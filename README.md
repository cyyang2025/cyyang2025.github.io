# Ching-Yu Yang | Personal Portfolio & Resume

A responsive, high-performance personal portfolio website highlighting projects in **Electronic Design Automation (EDA)**, **VLSI Physical Design Optimization**, and **Machine Learning**.

🌐 **Live Website:** [https://cyyang2025.github.io](https://cyyang2025.github.io)

---

## 🛠️ Built With

- **HTML5**: Semantic markup with full accessibility considerations.
- **CSS3**: Custom design system using CSS Variables (`:root`), Flexbox, CSS Grid, smooth transitions, and `@media print` support for PDF generation.
- **Vanilla JavaScript**: Lightweight DOM manipulation for real-time project filtering and dark/light mode toggle with `localStorage` persistence.

---

## 📂 Project Structure

```text
.
├── index.html       # Structure and content
├── style.css        # Responsive styling and theme tokens
├── script.js        # Interactive filtering and theme toggle
└── README.md        # Project documentation
```

## 💻 Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/cyyang2025/cyyang2025.github.io.git
cd cyyang2025.github.io

# Start a local web server (Python 3)
python3 -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
